# ps1/ — PlayStation platform layer

Copied from `RSDKv2-ps1/ps1/` at commit `e7cc7d4` (2026-09-24; older notes cite `d5e054b`, the same commit before a
history rewrite) and adapted freely for Sonic CD (user decision, `../../docs/28`). The RSDKv4 port copied this folder
in turn (`RSDKv4-ps1/ps1/`). Each file's header describes it in full; the Nexus-era notes in them still apply unless
changed here.

| File | Role |
|---|---|
| `render.cpp` | the GPU renderer: replaces `RSDKv3/Drawing.cpp` (tile layers, BG strips, atlas sprites, 3D floor, Scene3D, fades) |
| `gpu_chain.{cpp,hh}` | the per-frame DMA chain: per-parity arenas, bulk fragments linked with one `chain()` |
| `tileset.{cpp,hh}`, `sprite_atlas.{cpp,hh}` | stage-load VRAM uploads: tile pages (`16x16Tiles.vram`) and the per-player sprite atlases |
| `cdrom_fs.cpp` | file I/O: ISO9660 + the on-disc file index, the load stream (continuous ReadN, header-checked sectors) |
| `cdrom_stream.{cpp,hh}` | continuous sector streaming for STR video; bounded close with abort (`../../docs/40`) |
| `xa_music.{cpp,hh}` | CD-XA music (68 tracks in 8 channels, loop points); bounded waits with abort (`../../docs/40`) |
| `spu.{cpp,hh}` | SPU driver on the ps1-bare-metal model (sample upload, voices) |
| `mdec.{cpp,hh}`, `video.{cpp,hh}` | MDEC + VLC driver (PSn00bSDK psxpress port, MPL) and the STR player (PIO / hybrid / DMA modes) |
| `fmv.{cpp,hh}` | full-screen FMV for the engine's video calls: letterbox, JP / US audio channel, diagnostics strip (SELECT) |
| `irq_guard.{cpp,hh}` | lost-IRQ guard for psyqo's I_STAT acknowledge, stale CD latches and orphan CD answers (`../../docs/31`, `40`) |
| `loading.{cpp,hh}`, `loading_icon.h` | the loading indicator; `loading_icon.h` is generated (see below) |
| `memcard.{cpp,hh}`, `memcard_icons.h` | memory card saves (slot 1, one block, CRC); icons generated by `tools/memcard/build_icons.py` |
| `memcard_test.cpp` | memory card self-test (`make MEMCARD_TEST=1`, `tools/memcard/selftest.sh`) |
| `pc_sampler.cpp` | PC sampler for profiles (`make SAMPLE=1`, `tools/play/scene_run.sh SAMPLE=1`) |
| `platform_test.cpp` | the phase 0 smoke test (`make PLATFORM_TEST=1`, `tools/smoke_test.sh`) instead of the engine |
| `libc/` | our libc / C++ header shims (maths checked against PC values) |

Differences from the RSDKv2 copy:
- `loading_icon.h` is generated from `PS1/Memcard icons/sonic-1-loading.gif` (Sonic running,
  4 frames, reduced to 48x48 cells, 83 ms/frame) by `tools/loading/build_icon.py` (its line 1 names the source).
  Artwork: "Sonic Running" GIF by Salmon270 on Tenor, as the public builder credits it
  (https://tenor.com/en-GB/view/sonic-running-run-fast-gotta-go-fast-pixel-art-gif-16947491).
- `platform_test.cpp` (the phase 0 smoke test) stood in for the engine's `main.cpp` until phase 2; it is kept as a test
  build.
